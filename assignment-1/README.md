# Assignment 1

This folder contains Assignment 1 materials and scripts.

## Contents

- `8-queens-problem/` - CNF generation and sample solutions for 8-Queens.
- `clique-problem-slides/` - clique-to-SAT examples and model decoding scripts.
- `vertex-cover-slides/` - vertex-cover-to-SAT examples and model decoding scripts.
- `prolog/` - small Prolog exercises.

## How to Use

Most files are class examples or generated outputs. Open each subfolder and run scripts with `python3` as needed.

Example:

```bash
cd assignment-1/8-queens-problem
python3 make_8queens_cnf.py
```
